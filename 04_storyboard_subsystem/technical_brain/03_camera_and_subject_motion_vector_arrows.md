# CAMERA & SUBJECT MOTION VECTOR NOTATION (`technical_brain/03_camera_and_subject_motion_vector_arrows.md`)

## 1. STANDARDIZED VECTOR FORMULATION
In Sub-System 04, spatial kinetics are coded via deterministic vector tags:

| Vector Code | Description | Visual Storyboard Notation |
| :--- | :--- | :--- |
| `[CAM: Z+ PUSH 0.52m]` | Camera forward push along optical axis | Thick 3D arrow pointing into depth on floor plane |
| `[CAM: Z- PULL]` | Camera backward tracking | Arrow pointing down toward viewer |
| `[CAM: X+ PAN / TRACK]` | Lateral track or pan from left to right | Horizontal right-pointing arrow |
| `[FOCUS: RACK 1.5m -> 4.2m]` | Focus transition between planes | Curved depth rings with distance tags |
| `[SUBJ_01: STATIC]` | Character stationary | Fixed circle with actor UUID |
| `[SUBJ_02: MICRO-HAND_MOTION]`| Micro movement in hands/face | Small kinetic loop vector around prop |
| `[ENV: Y- DRIP_VECTOR]` | Environmental water falling | Vertical downward hatched arrows |
