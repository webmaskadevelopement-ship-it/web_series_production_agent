# PROP TAXONOMY: HERO ACTION, SET & CONSUMABLE (`technical_brain/01_prop_taxonomy_hero_action_set_consumable.md`)

## 1. THREE-TIER PRODUCTION CATEGORIZATION

| Category Tier | Production Requirement | Duplicates Required | Operational Rules |
| :--- | :--- | :--- | :--- |
| **Category A: Hero Action Prop** | Directly handled by principal actors in Macro/ECU shots. Advances narrative or reveals character. | **3 Identical Copies:** 1 Hero Macro pristine copy, 1 Stunt/Drop copy, 1 Flashback/Clean copy. | Detailed PBR specifications, exact dimensional tolerances, acoustic transient logs. |
| **Category B: Set Dressing** | Populates niches, tables, and ledgers to create lived-in entropy. | 1 Set (backed up with photographic continuity stills). | Surface reflectance and historical oxidation specs. |
| **Category C: Consumable** | Depleted, destroyed, torn, or ingested during takes (e.g., garlic cloves, matchsticks, land deed papers). | **12 to 24 Sets** (to support multiple takes). | Exact reset protocol and matching depletion states. |
